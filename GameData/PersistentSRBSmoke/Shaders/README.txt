PersistentSRBSmoke true raymarched volumetric renderer

Expected bundle:
PersistentSRBSmokeVolumetric.shab

Place the compiled .shab file in this directory and install Shabby so KSP can load the custom shader.

Without the .shab bundle, PersistentSRBSmoke automatically uses its dependency-free 3D slice-volume fallback.
